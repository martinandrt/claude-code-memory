# /boot — start of session

Read the boot layer, get oriented, hand control back. Don't start work.

## 1. Read (in parallel)

- `memory/BRAIN.md` — operating manual + decision rules
- `memory/LINEAGE.md` — the last session's handoff
- `memory/MEMORY.md` — the lookup index (so you know *what exists*, without loading it)
- the last ~10 lines of your activity log, if you keep one

Do **not** open the on-demand folders (`feedback/`, `knowledge/`, `projects/`, `reference/`). Those load later, only when a task needs them.

## 2. Internalize — do not recite

Understand the last session: what it was, what's half-finished, what must not be touched. Map the open items.

**Do not dump the files back at the user.** They wrote them and can see them. Recitation wastes tokens and attention. The metric is *orientation*, not *summary*.

## 3. Output a short status (a few lines)

- Which session this is and what it continues
- Anything notable since last time (ignore noise in the log)
- End with "what are we doing?" — then stop and wait

That's it. Boot orients; it doesn't act.
